## 📌 معرفی پروژه

این سرویس یک **ربات تلگرامی خودکار** است که هر ۵ دقیقه یک بار قیمت لحظه‌ای طلا و دلار را از سایت [ایران جیب](https://www.iranjib.ir) دریافت کرده و به‌همراه میزان تغییرات (به ریال و درصد) به یک کانال یا گروه تلگرامی ارسال می‌کند.

ربات به‌صورت یک **وب‌سرویس Flask** طراحی شده و برای اجرای پایدار روی پلتفرم‌هایی مانند **Render.com**، **Heroku** یا هر سرور لینوکسی مناسب است.

---

## ✨ ویژگی‌ها

- دریافت خودکار قیمت طلا (به تومان) و دلار (به تومان) از منبع معتبر
- محاسبه و نمایش تغییرات روزانه به ریال و درصد
- ارسال پیام‌های منظم هر ۵ دقیقه به گروه/کانال تلگرام
- دارای مسیرهای `/` و `/health` برای مانیتورینگ سلامت سرویس
- استفاده از **متغیرهای محیطی** برای ذخیره امن توکن و شناسه گفت‌وگو
- قابلیت اجرا روی سرویس‌های ابری با پشتیبانی از Gunicorn

---

## 🛠️ پیش‌نیازها

- Python 3.8 یا بالاتر
- یک ربات تلگرامی با توکن معتبر (ساخته شده توسط [@BotFather](https://t.me/BotFather))
- شناسه عددی گروه/کانال مقصد (می‌توانید با ربات [@GetMyIDBot](https://t.me/GetMyIDBot) دریافت کنید)
- اتصال به اینترنت برای دریافت داده از سایت و ارسال به تلگرام

## 📦 نصب و راه‌اندازی محلی

### ۱. کلون کردن مخزن

```bash
git clone https://github.com/Etehad/Tala.git
cd Tala
```

### ۲. ایجاد محیط مجازی (پیشنهادی)

```bash
python -m venv venv
source venv/bin/activate   # در ویندوز: venv\Scripts\activate
```

### ۳. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

محتوای `requirements.txt`:

```
Flask==2.3.2
requests==2.31.0
beautifulsoup4==4.12.2
gunicorn==21.2.0
```

### ۴. تنظیم متغیرهای محیطی

ربات برای دریافت توکن و شناسه گفت‌وگو از متغیرهای محیطی استفاده می‌کند. **هرگز این مقادیر را به‌صورت مستقیم در کد قرار ندهید.**

دو روش برای تنظیم متغیرها وجود دارد:

#### روش خط فرمان (Linux/macOS)

```bash
export BOT_TOKEN="XXX"
export CHAT_ID="XXX"
```

#### روش فایل `.env` (پیشنهادی برای توسعه)

یک فایل به نام `.env` در ریشه پروژه بسازید و بنویسید:

```
BOT_TOKEN=XXX
CHAT_ID=XXX
```

سپس برای بارگذاری آن می‌توانید از کتابخانه `python-dotenv` استفاده کنید (در صورت نیاز).

### ۵. اجرای سرویس

برای اجرای مستقیم (توسعه):

```bash
python app.py
```

برای اجرا با Gunicorn (محصولی):

```bash
gunicorn app:app
```

سپس سرویس روی پورت پیش‌فرض `8000` در دسترس خواهد بود.

## ☁️ استقرار روی Render.com

۱. مخزن خود را به GitHub ارسال کنید.  
۲. در Render.com یک **Web Service** جدید ایجاد کرده و مخزن را متصل کنید.  
۳. در بخش **Environment Variables** دو متغیر زیر را با مقادیر خود اضافه کنید:

| Key          | Value                               |
|--------------|-------------------------------------|
| `BOT_TOKEN`  | `XXX` |
| `CHAT_ID`    | `XXX` |

۴. دستور شروع (Start Command) را به‌صورت زیر تنظیم کنید:

```
gunicorn app:app
```

۵. روی **Deploy** کلیک کنید. پس از اتمام ساخت، ربات به‌طور خودکار کار خود را آغاز می‌کند.
